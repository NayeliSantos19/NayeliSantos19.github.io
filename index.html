CASO DE ESTUDIO / 01

Proyecto de aprendizaje · Web

Ritmo.
Del hábito a la interfaz.

Una aplicación personal para registrar el estudio, visualizar el progreso y dedicar tiempo al enfoque.

Probar la aplicación ↗Revisar el código ↗
EL PROBLEMA

El registro de lo estudiado y los momentos de concentración suelen estar separados. Ritmo los reúne en un mismo espacio.

EL ALCANCE

Interfaz, registro de sesiones, meta semanal y temporizador. Proyecto desarrollado con asistencia de Codex como parte de mi formación.

LA BASE TÉCNICA

HTML semántico, CSS y JavaScript sin framework. Persistencia local con localStorage y publicación en GitHub Pages.

DECISIONES QUE DAN FORMA AL PROYECTO

Qué hace el código.
Y qué implica.

01

Empezar sin crear una cuenta

Las sesiones y la meta se guardan en localStorage. Permite probar la aplicación de inmediato y conservar los datos al recargar. A cambio, no hay sincronización entre dispositivos y borrar los datos del navegador elimina el historial local.

02

Calcular el progreso desde las sesiones

El panel agrupa los minutos por fecha, de lunes a domingo, y compara el total semanal con una meta editable. El resumen se deriva del mismo registro que alimenta la lista de sesiones.

03

Reducir distracciones con una opción explícita

El modo inmersivo presenta el temporizador con menos elementos alrededor. Se puede salir con Escape. Las duraciones sugeridas según la energía siguen reglas sencillas; la persona mantiene la elección.

04

Validar antes de guardar

El formulario exige tema, materia y minutos enteros entre 1 y 1440, y evita fechas futuras. Los textos de las sesiones se escapan antes de insertarlos en el HTML.

PRUEBA EL RECORRIDO

Una revisión en tres pasos

  1. Registra una sesión y comprueba el resumen y la gráfica.
  2. Recarga la página para comprobar la persistencia local.
  3. Prueba el temporizador, su pausa y el modo inmersivo.

Para revisar el prototipo; no representa resultados de pruebas con usuarios.

LÍMITES Y SIGUIENTE ITERACIÓN

Qué falta por resolver

La exportación JSON permite descargar el registro, pero todavía no existe un flujo de importación. Tampoco hay cuentas ni respaldo en la nube.

El siguiente paso propuesto es probar el flujo con estudiantes, recoger dificultades concretas y mejorar la recuperación de datos antes de ampliar funciones.
